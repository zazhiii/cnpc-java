# 本地开发中间件 Docker 安装与验证

本文记录本项目在 Windows + Docker Desktop 环境中已经实际执行并验证成功的中间件部署流程。

## 1. 项目实际需要的中间件

根据 `yudao-server/src/main/resources/application-local.yaml` 和项目自带 SQL，当前本地开发必须使用：

| 中间件 | Docker 镜像 | 容器名 | 宿主机端口 | 容器端口 |
| --- | --- | --- | --- | --- |
| MySQL | `mysql:8.0.33` | `yudao-mini-mysql` | `13306` | `3306` |
| Redis | `redis:6.2-alpine` | `yudao-mini-redis` | `16379` | `6379` |

RabbitMQ、Kafka 和 RocketMQ 在配置中仅作为可选示例。当前 `yudao.websocket.sender-type` 为 `local`，因此本地启动不需要安装这些消息队列。

本机已有原生 MySQL 和 Redis 分别占用 `3306`、`6379`。为避免停止或影响已有服务，本项目 Docker 容器改用 `13306`、`16379`，并已同步修改 `application-local.yaml`。

## 2. 已落地的文件

- Docker Compose：`script/docker/docker-compose.middleware.yml`
- MySQL 业务初始化脚本：`sql/mysql/ruoyi-vue-pro.sql`
- Quartz 初始化脚本：`sql/mysql/quartz.sql`
- 本地应用配置：`yudao-server/src/main/resources/application-local.yaml`

MySQL 数据和 Redis AOF 数据保存在 Docker 命名卷中，普通的容器重建或重启不会清空数据。

## 3. 启动中间件

在项目根目录执行：

```powershell
docker compose -f script/docker/docker-compose.middleware.yml up -d
```

首次启动会执行以下工作：

1. 拉取 MySQL 8.0.33 和 Redis 6.2 Alpine 镜像。
2. 创建持久化数据卷。
3. 创建数据库 `ruoyi-vue-pro`。
4. 按顺序导入业务 SQL 和 Quartz SQL。
5. 启动健康检查。

初始化 SQL 仅在 MySQL 数据卷为空时自动执行。

## 5. 已执行的成功验证

### 5.1 查看健康状态和端口

```powershell
docker compose -f script/docker/docker-compose.middleware.yml ps
```

验证结果：

```text
yudao-mini-mysql  Up (healthy)  0.0.0.0:13306->3306/tcp
yudao-mini-redis  Up (healthy)  0.0.0.0:16379->6379/tcp
```

### 5.2 验证 MySQL

```powershell
docker exec yudao-mini-mysql mysql -uroot -p123456 -D ruoyi-vue-pro -Nse "SELECT VERSION(), DATABASE(); SELECT COUNT(*) FROM information_schema.tables WHERE table_schema='ruoyi-vue-pro'; SELECT COUNT(*) FROM information_schema.tables WHERE table_schema='ruoyi-vue-pro' AND table_name LIKE 'QRTZ_%'; SELECT COUNT(*) FROM system_users;"
```

2026-07-22 的实际结果：

```text
8.0.33  ruoyi-vue-pro
59
11
20
```

含义依次为 MySQL 版本和当前库、当前库总表数、Quartz 表数、初始化用户记录数。

### 5.3 验证 Redis

```powershell
docker exec yudao-mini-redis redis-cli PING
```

实际结果：

```text
PONG
```

### 5.4 验证宿主机端口

```powershell
Test-NetConnection 127.0.0.1 -Port 13306 -InformationLevel Quiet
Test-NetConnection 127.0.0.1 -Port 16379 -InformationLevel Quiet
```

两个命令的实际结果均为 `True`。

## 6. 日常管理命令

查看状态：

```powershell
docker compose -f script/docker/docker-compose.middleware.yml ps
```

查看日志：

```powershell
docker compose -f script/docker/docker-compose.middleware.yml logs -f mysql redis
```

停止容器但保留数据：

```powershell
docker compose -f script/docker/docker-compose.middleware.yml stop
```

重新启动：

```powershell
docker compose -f script/docker/docker-compose.middleware.yml start
```

删除容器但保留数据卷：

```powershell
docker compose -f script/docker/docker-compose.middleware.yml down
```

## 7. 重新初始化数据库

只有明确要丢弃本项目 Docker 中的 MySQL 和 Redis 数据时，才执行：

```powershell
docker compose -f script/docker/docker-compose.middleware.yml down -v
docker compose -f script/docker/docker-compose.middleware.yml up -d
```

`down -v` 会永久删除此编排的 MySQL、Redis 数据卷，之后 MySQL 才会重新执行初始化 SQL。执行前应先备份需要保留的数据。

## 8. 启动后端前检查

确认 `application-local.yaml` 中以下值保持一致：

```yaml
spring:
  datasource:
    dynamic:
      datasource:
        master:
          url: jdbc:mysql://127.0.0.1:13306/ruoyi-vue-pro
        slave:
          url: jdbc:mysql://127.0.0.1:13306/ruoyi-vue-pro
  data:
    redis:
      host: 127.0.0.1
      port: 16379
```

JDBC URL 中的其他连接参数继续保留项目原配置即可。
